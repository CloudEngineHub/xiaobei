# 原帖与网页引用截图

用户要求把真实网页或社交原帖作为引用素材时使用；只采集证据，不因此启动制作或发布。

1. 按平台先用 `weibo-hunter` / `x-hunter` / `douyin-hunter` / `xhs-hunter` / `tiktok-hunter` / `kuaishou-hunter` / `wx-mp-hunter` 获取资料；普通站点用 `smart-search`。采集失败不自动换浏览器绕行。需要真实页面截图时按本技能与对应平台登录约定访问；API 认证不等于浏览器已登录，不复制 API Cookie 造登录。
2. 先创建本任务素材目录与来源说明，记录 URL、作者、发布日期、采集时间及已核对的正文。区分原作者、转述媒体和被报道人物。截图前展开可见正文、核对账号与日期，检查登录提示、浮层或裁剪是否挡字。
3. 保留未改动截图。优先截取包含所需引文的可见窗口；确需整页截图时先保存原件，超长图先裁再查看，不把某次查看器的像素上限写成固定平台限制。DOM 可读不代表截图可见。
4. 需要按 DOM 裁切时，保存同一页面布局、滚动位置下的几何数据为 JSON；截图期间页面变化则重新测量。视口截图用 `getBoundingClientRect()` 的 x/y，captureWidth/Height 为实际 CSS 视口；整页截图用 x/y 加 scrollX/Y，captureWidth/Height 为截图实际覆盖的 CSS 文档大小。不要只用 devicePixelRatio 猜倍率。

几何文件格式（数值必须是本次实测）：

```json
{"captureWidth":1200,"captureHeight":800,"x":100,"y":80,"width":600,"height":400}
```

```bash
browser-guide crop-evidence --source /绝对路径/original.png --geometry /绝对路径/geometry.json --output /绝对路径/quote.png
```

脚本按截图实际像素尺寸换算并检查比例、边界，只做 PNG 裁切，不覆盖原件。裁切后目视核对关键句完整、清晰、无遮挡；布局或比例无法确认时重新截图，不猜坐标。不要移除登录层、重绘原帖或把提取文字伪装成截图。关键句被挡住时明确截图未取得，按平台登录流程处理。

交接时同包保存正文、原件、可用裁切和说明，列出绝对路径、用途、遮挡限制、作者、日期与原链接。裁切缺作者栏时在图外补署名；翻译单列为“译意/节译”，不覆盖原文。区分本人原话、媒体概括与创作者延伸，旧表态不能包装成今日新表态，相关观点不自动构成产品背书。成品只引用必要内容。

向用户交付图片时使用当前渠道的媒体工具发送图片本体；仅本地查看或报路径不算发送。委托 Content Producer 时按 Brief 和素材交接约定传路径，不擅自向用户发信。
